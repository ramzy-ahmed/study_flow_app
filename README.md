# Flashcard Quiz App

The **Flashcard Quiz App** is your ultimate Android study buddy for **creating, quizzing, and conquering knowledge**. Build custom flashcard decks, edit on the fly, and test yourself with **randomized quizzes** that keep every session fresh and challenging.

Track scores, spot weaknesses, and celebrate progress—all in a **sleek, distraction-free interface** powered by **Java**, **MVC architecture**, and **local SharedPreferences**. Whether prepping for exams, learning languages, or sharpening skills, this app turns **study time into smart time**.

> *This isn't just flashcards—it's your personal learning accelerator, blending simplicity, science, and style to help you retain more, faster.*

---

## ✨ Key Features

| Feature | Description |
|--------------------------|-----------------------------------------------------------------------------|
| **Full Flashcard Control** | Create, edit, or delete cards with questions, answers, and hints—build decks your way. |
| **Dynamic Quiz Engine** | Randomized, shuffled questions every time—no memorizing order, just real learning. |
| **Instant Feedback & Scoring** | Real-time correct/incorrect results with final score and breakdown. |
| **Progress Tracking** | Auto-saved quiz history: review scores, dates, and improvement trends. |
| **Clean & Focused UI** | Minimalist Material Design with smooth transitions, large text, and gesture-friendly flow. |
| **Offline & Private** | 100% local via SharedPreferences—no internet, no accounts, full control. |
| **MVC Architecture** | Clear separation for fast performance and easy expansion. |

## 🛠️ Installation

### Prerequisites
- **Android Studio**: Version Giraffe (2022.3.1) or later
- **SDK Versions**: Min SDK 21 (Android 5.0), Target SDK 34
- **Java**: Version 8 or higher

### Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/ramzy-ahmed/Flashcard-Quiz-App.git
   ```
2. Open the project in Android Studio.
3. Sync Gradle dependencies.
4. Build and run:
   ```bash
   # From Android Studio: Click Run
   ```

> **Note**: Works instantly offline—no setup, no login, just study.

## 🚀 Usage

Master any topic in minutes:
1. **Launch App** → Create a new deck (e.g., "Spanish Verbs").
2. **Add Cards** → Enter question, answer, optional hint.
3. **Start Quiz** → Tap "Begin" → answer shuffled questions.
4. **Get Results** → See score, review mistakes, retry weak cards.
5. **Track Progress** → View history and watch your improvement grow.

**Pro Tip**: Use "Flip on Tap" for faster review or "Hard Mode" to hide hints.
